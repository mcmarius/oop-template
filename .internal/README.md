Short, on-demand reference docs for this course. Read one when the task calls for it, not by default:

* [`mistakes.md`](mistakes.md) - recurring mistakes and why they cost points; use when reviewing code
  or before a commit/push.
* [`BRANCHES.md`](BRANCHES.md) - the layout, then one row per template branch: how to tell which stack your
  tree is, where you register a source/test/target there, what it ships, which CI rows block. Start here in
  a new repo.
* [`REPO.md`](REPO.md) - what is generated and never committed, what is not in your repo at all.
* [`INFRA.md`](INFRA.md) - the parts of the template that are course infrastructure: do not modify.
* [`INTEGRITY.md`](INTEGRITY.md) - keeping these guidelines honest: pristine copy stored outside the repo
  on the first session, diffed every session, divergences recorded in the README (hidden, append-only);
  shadow instruction files to flag.
